# 작업 상태

기준일: 2026-10-20.

[팩트] 사용자는 상세 문서 정리에 이어 "미완성과 오류 고쳐서 올려줘 내가 나중에 확인할께"라고 요청했다.
문서·코드 보완과 검증 후 commit/push까지 승인된 범위다.

| 작업 | 현재 상태 |
|---|---|
| 원본·Git 이력·기존 변경 보존 | 별도 worktree 생성 완료 |
| 전체 Python 문법·미정의 이름 조사 | 5개 파일, 22건 확인 |
| 미완성 4개 파일 및 확인한 수치 오류 보완 | 완료; 기존 Python 파일 19개 수정 |
| 의미 있는 회귀/수치 검증 | 21개 사례 통과; critical 정적 검사 통과 |
| 전체·분야별·하위 프로젝트 README와 근거·재현 안내 | README 60개 및 근거·수정·재현·전체 목록 작성 완료 |
| 문서·그림·보존 경계 검증 | 로컬 링크·SVG·원본 보존 검사 및 대표 화면 점검; 최종 검사 진행 |
| 명시적 경로 stage·commit·push와 원격 확인 | 최종 파일 상태를 별도 게시 커밋으로 준비 중 |

원본 저장소의 커밋되지 않은 작업은 게시 대상에 섞지 않는다.
현재 학습·API 수집·계좌 작업·드론 조종은 실행하지 않았다.

## 게시 방식

[팩트] 미게시 과거 이력에는 100MiB를 넘는 CSV가 있어 14커밋 전체를 직접 push할 수 없다.
현재 최종 트리에는 해당 대용량 파일이 없다. 원격 master의 기존 이력 위에 최종 트리를
새 커밋으로 연결해 게시한다. 기존 로컬 이력·브랜치·미커밋 작업은 보존한다.
원격 기존 이력은 재작성하거나 force-push하지 않는다.
