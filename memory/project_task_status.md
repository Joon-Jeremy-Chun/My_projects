기준일: 2026-10-20.

문서·코드 보완과 검증 후 commit/push까지 승인된 범위다.

원본 저장소의 커밋되지 않은 작업은 게시 대상에 섞지 않는다.
현재 학습·API 수집·계좌 작업·드론 조종은 실행하지 않았다.

## 게시 방식

[팩트] 미게시 과거 이력에는 100MiB를 넘는 CSV가 있어 14커밋 전체를 직접 push할 수 없다.
현재 최종 트리에는 해당 대용량 파일이 없다. 원격 master의 기존 이력 위에 최종 트리를
새 커밋으로 연결해 게시했다. 기존 로컬 이력·브랜치·미커밋 작업은 보존했다.
원격 기존 이력은 재작성하거나 force-push하지 않았다.

[팩트] 구현·문서 게시 커밋은 `5b2833eb68a75399a9239b816ec6206b66f5e9be`다.
push 성공 후 `git ls-remote --heads origin master` 결과와 로컬 SHA가 일치했다.
게시용 worktree는 `my_projects-publish-20261020`, 브랜치는
`codex/portfolio-publish-20261020`다. 원래 작업 폴더의 master는 바꾸지 않았다.
후속 작업은 원격 master 또는 게시 브랜치에서 시작하며 완료 기록은 별도 문서 커밋으로 남긴다.
